# QuickGoogle

Быстрый поиск имени выбранного файла в Google через контекстное меню Проводника Windows.

> [Прямая ссылка v1.0.0](https://github.com/nivemoon/QuickGoogle/releases/download/v1.0.0/QuickGoogle-v1.0.0-windows-x64.zip)

## Возможности

- Добавляет пункт «Искать в Google» в контекстное меню файлов.
- Ищет по имени выбранного файла.
- Работает для текущего пользователя.
- Не требует прав администратора.
- Устанавливается в любую удобную папку.
- После установки не требует отдельной программы, работающей в фоне.

## Требования

- Windows 10 или Windows 11.
- 64-разрядная Windows.
- Проводник Windows.
- PowerShell для установки.

## Установка

1. Скачайте готовую версию из раздела Releases или склонируйте репозиторий.
2. Поместите следующие файлы в одну папку:

   - `GoogleSearchContext.dll`
   - `install.ps1`
   - `uninstall.ps1`

3. Откройте PowerShell в этой папке.
4. Выполните:

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\install.ps1
```

После установки при нажатии правой кнопкой по файлу появится пункт:

```text
Искать в Google
```

Если пункт не появился сразу, перезапустите Проводник Windows.

## Удаление

Перед переносом или удалением папки запустите:

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\uninstall.ps1
```

После удаления регистрации папку с файлами можно удалить.

## Как это работает

QuickGoogle реализован как native COM DLL — расширение контекстного меню Проводника Windows.

После выбора команды расширение:

1. Получает путь к выбранному файлу.
2. Берёт имя файла.
3. Формирует поисковый запрос.
4. Открывает Google в браузере по умолчанию.

Сам выбранный файл не запускается и не изменяется.

## Важные замечания

- Расширение регистрируется только для текущего пользователя.
- Для регистрации используются записи в `HKCU\Software\Classes`.
- Права администратора не требуются.
- После перемещения DLL необходимо снова запустить `install.ps1`.
- Перед удалением папки необходимо запустить `uninstall.ps1`.
- Для неподписанной DLL Windows или антивирус может показать предупреждение.
